# 10 — Set up the page on your phone (about 20 minutes)

The graphics are ready in `images/`. Send them to your phone (WhatsApp to yourself, Google Drive, or download from GitHub), then do these steps in order. Everything you type is copy-paste from `01-page-identity.md`.

## 1. Create the account
1. Instagram → Add account → Create new account
2. Username: `billi.explains.ai` (taken? try `aibilli.daily` → `meow.ai.tips` → `ai.wali.billi`)
3. Name: `AI Billi | AI Tips`
4. Settings → Accounts Centre → Password and security → **Two-factor authentication: ON**

## 2. Make it a creator account
Settings → Account type and tools → Switch to professional account → **Creator** → category **Digital creator** → Show category on profile: ON. Skip contact options.

## 3. Bio
Edit profile → Bio → paste:
```
Ek billi, roz ek AI trick 🐱
Hinglish me, free
Prompt pack ke liye DM 'AI' 👇
```

## 4. Link in bio
Edit profile → Links → Add external link. Title `Free AI Prompt Pack`, URL = your published Notion page (paste Part A of `05-free-prompt-pack.md` into Notion → Share → Publish).

## 5. Profile picture
Still needs your cat: run prompt P1 from `02-image-prompts.md` with your cat's photo, save it as `images/master/MASTER.png`, upload it. Check that the face is clear at thumbnail size.

## 6. Start Here stories + 5 highlights
1. Post `images/stories/start-here-1.png`, `-2.png`, `-3.png` as three stories, in that order. Optional: add MASTER.png as a sticker on story 1, over the glasses.
2. Profile → **+** → Highlight → pick all 3 → name it `Start Here` → Edit cover → choose `images/highlights/start.png`.
3. The other four highlights need one story each. Post any story, e.g. a prompt screenshot, then create them:

| Highlight | Cover file |
|---|---|
| Start Here | `images/highlights/start.png` |
| Prompts | `images/highlights/prompts.png` |
| AI Tools | `images/highlights/tools.png` |
| Jobs | `images/highlights/jobs.png` |
| Study | `images/highlights/study.png` |

## 7. Saved replies for keyword DMs
Settings → Business tools and controls → Saved replies → add one per keyword in Part B of `05-free-prompt-pack.md`, with shortcut `/` + keyword in lowercase (e.g. `/resume`). Start with `/ai`, `/tools`, `/prompt`, `/ppt` and `/resume` (Days 1–4).

After that, the page is ready. Continue from Day 4 of `03-launch-sprint.md`.
