# 04 — 30 reel scripts (ready to shoot)

**How each reel works (50 seconds, 5 clips of 10 seconds):**
- **Clip 1 (Flow, P6):** the cat says the hook. Hook text sits in the top third.
- **Clips 2–4 (your screen recording):** the cat sits small in a corner; you show the real steps; subtitles on.
- **Clip 5 (Flow, P6):** the cat celebrates and says the call to action. On screen: `Comment KEYWORD`.

For every Flow clip, start the prompt with your STYLE LINE from `02-image-prompts.md`, then add the ACTION and the Hindi line below. Default TONE: *warm, playful, confident*.

Series tag: each reel is **Billi Tip #N**. Put it in the cover corner and the caption.

**Caption template** (5 lines):
```
<hook>
<promise>
Comment <KEYWORD> aur main tumhe prompt DM kar dungi 📩
Save karo aur us dost ko share karo jisko iski zarurat hai 🐱
<hashtags>
```

> ⚠️ Before posting, check that every tool you mention is still free and still works the same way. Plans and features change often.
