# 🐱 AI Billi ka Free Prompt Pack
Roz ek AI trick, Hinglish me. Copy karo, `[ ]` wali jagah bhar do, aur kisi bhi AI chatbot (Gemini, ChatGPT, etc.) me paste karo.

> Tip: AI galti kar sakta hai. Important cheezein (facts, numbers, formulas) hamesha khud check karo.

### 1. The "ask me first" trick (PROMPT)
```
[Your task]. Before you answer, ask me 3 questions to understand exactly what I need. Then answer step by step.
```

### 2. Presentation in 1 minute (PPT)
```
Make a 6-slide presentation outline on [topic] for [audience]. For each slide give: a title, 3 short bullet points, and one image idea. Keep the language simple.
```

### 3. ATS-friendly resume (RESUME)
```
Here is a job description: [paste JD]. Here is my resume: [paste resume]. Rewrite my resume bullet points to match the important keywords in the JD. Use action verbs and numbers where they are true. Do not invent experience. Use a simple one-column format with no tables.
```

### 4. Notes to revision (NOTES)
```
Summarise this chapter in 10 bullet points a student can revise in 2 minutes. Then write 5 likely exam questions with short answers. [paste text or upload PDF]
```

### 5. Mock interview (INTERVIEW)
```
You are an interviewer for a [role] position at a [type of company]. Ask me one interview question at a time. After each answer, give me honest feedback and a better example answer. Start now.
```

### 6. Instagram captions (CAPTION)
```
Write 5 Hinglish Instagram captions for a post about [topic]. Each under 20 words, start with a hook, 1 emoji, and suggest 3 relevant hashtags.
```

### 7. Professional email (EMAIL)
```
Write a polite, professional email to [person/role] about [situation]. Keep it under 120 words, with a clear subject line and a specific request at the end.
```

### 8. Study tutor (STUDY)
```
Act as my tutor for [subject/chapter]. Quiz me one question at a time. If I'm wrong, explain simply with an example. At the end, make a 7-day revision plan for my weak topics.
```

### 9. AI image formula (IMAGE)
```
Create an image of [subject] [doing what], in [style] style, [setting], [lighting], [aspect ratio, e.g. 9:16]. No text in the image.
```

### 10. Explain like I'm 10 (EASY)
```
Explain [topic] like I'm 10 years old, using an everyday Indian example (cricket, chai, trains, etc.). Then give me one line to remember it.
```

### 11. Small business pack (BIZ)
```
I run a [business] selling [product] in [city]. Write: (1) a short WhatsApp offer message, (2) a product description for Instagram, (3) 5 polite reply templates for common customer questions about price, delivery and returns. Hinglish, friendly tone.
```

### 12. Chat with a PDF (PDF)
```
Using only the uploaded document, list the 5 most important points and give the page number for each. If something is not in the document, say "not found".
```

### 13. Prompt fix checklist (FIX)
Before you send any prompt, check: ✅ Context (who you are, the situation) ✅ Task (exactly what you want) ✅ Format (bullets, table, word limit) ✅ Role ("You are a…") ✅ Example (show one if you can) ✅ Then improve the answer with feedback.

### 14. LinkedIn upgrade (LINKEDIN)
```
I am a [role] with [X years / fresher] experience in [skills]. Write: (1) 3 LinkedIn headline options under 220 characters, (2) an About section in 3 short paragraphs, (3) 15 skills recruiters search for in [target role]. Don't exaggerate.
```

### 15. Excel/Sheets formula (EXCEL)
```
I'm using Google Sheets. My data: [describe the columns]. I want: [what you want to calculate]. Give me the formula and explain it in one line.
```

### 16. Monthly budget (BUDGET)
```
Create a simple monthly budget table with sections for income, fixed costs (rent, EMI, bills), variable costs (food, travel, shopping) and savings. Include Google Sheets formulas for the totals and the % of income saved.
```

### 17. 30-day content calendar (CALENDAR)
```
My niche is [niche] and my audience is [audience]. Make a 30-day content calendar as a table: day, content pillar, topic, hook line, format (reel/carousel/story). Use 4 pillars and rotate them.
```

### 18. AI video formula (VIDEO)
```
[One fixed style sentence describing your character and look.] The [subject] [action] in [setting]. Camera: [slow push-in / pan]. Mood: [mood]. 9:16.
```

### 19. Give AI a role (ROLE)
```
You are an experienced [HR manager / chartered accountant / school teacher / marketing expert] with 15 years of experience in India. [Your question]. Be practical and specific.
```
10 roles to try: HR manager, career coach, school teacher, CA, marketing expert, copywriter, fitness coach, travel planner, lawyer (general information only), software mentor.

### 20. Freelance proposal (PROPOSAL)
```
Here is a job post: [paste]. Write a proposal under 120 words: start with their problem, then my 3-step plan, then one relevant example from my work: [your real example]. Friendly, confident, no clichés.
```

### 21. Logo ideas (LOGO)
```
Give me 10 logo concepts for [business name], a [type of business]. Simple, flat, max 2 colours, works at small size. Describe each in one line.
```
Check trademarks before you use a logo commercially.

### 22. Better feedback (FEEDBACK)
```
Keep [what you liked]. Change [what to change]. Make it [shorter/simpler/more formal]. Add [an example / a table].
```

### 23. Automate daily tasks (AUTO)
```
Here are tasks I do every day: [list]. For each one, tell me if it can be automated or sped up with free tools (Gmail filters, Google Calendar, Sheets, AI chatbots), and give exact steps.
```

### 24. Learn AI for your job (TRUTH)
```
I work as [job]. Which 3 tasks in my work can AI help with today? For each, give one free tool and a 15-minute practice exercise.
```
