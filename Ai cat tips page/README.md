## Decisions made for you (change them only on Day 2, never after)

| Blank | Chosen value | Why |
|---|---|---|
| Handle | `billi.explains.ai` (backup: `aibilli.daily`) | Clear, no brand names |
| Display name | `AI Billi \| AI Tips` | Searchable keyword "AI" |
| Bio | Option C | Has who, what, and one action |
| [STYLE] | **D. Flat sticker** — `flat vector sticker style, thick clean outline, bright flat colours` | Reads best at small size (profile pic, covers) |
| [BRAND COLOUR] | **deep teal** (#0F5C63) | Contrasts with most cat fur colours |
| [ACCENT COLOUR] | **warm orange** (#F28C28) | Pops against teal for text and highlights |
| [SIGNATURE ITEM] | **small round glasses** | Makes it look like a "teacher" cat |
| [CAT] | **YOU fill this in** — e.g. "orange tabby with white paws and green eyes" | Only you know your cat. Attach your cat's photo too. |

> If your cat is teal, grey-blue or very dark, swap the brand colour to **warm mustard yellow** (#E8B21E) so the cat stands out.

2. Take/attach your cat's photo and run the image prompts in Gemini / Flow.
3. Record the screen recordings for clips 2–4 of each reel.
4. Post, reply to comments, and send the DMs.
5. Check every AI tool's free plan on the day you post. Plans change.
