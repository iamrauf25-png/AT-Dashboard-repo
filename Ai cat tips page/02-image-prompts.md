# 02 — Image prompts (blanks filled)

Before you start, replace **`[CAT]`** everywhere with a description of your cat, for example `orange tabby with white paws and green eyes`. Use Find & Replace so it's identical in every prompt. Everything else is already filled in.

**Fixed values:**
- STYLE = `flat vector sticker style, thick clean outline, bright flat colours`
- BRAND COLOUR = `deep teal` · ACCENT COLOUR = `warm orange`
- SIGNATURE ITEM = `small round glasses`

**Workflow:** run P1 (pick 1 out of at least 4) → save it as **MASTER.png** → attach MASTER.png to every prompt after that.

Suggested folders inside this one:
```
images/master/        MASTER.png, character-sheet.png
images/highlights/    start.png, prompts.png, tools.png, jobs.png, study.png
images/poses/         the 8 pose images from P3
reels/day-01/ ... reels/day-30/   clips, cover, final video
```

## P1 — Profile picture (1:1)
Attach: a photo of your cat
```
Friendly cat mascot based on the attached photo of my cat ([CAT]). Head-and-shoulders portrait, centered, curious smile, looking at the viewer, wearing small round glasses. Flat vector sticker style, thick clean outline, bright flat colours. Solid deep teal background, bold simple shapes, high contrast, still readable at thumbnail size. Square 1:1. No text, no logos, no watermark.
```
Check it at thumbnail size. If the face isn't clear, ask for "even simpler shapes, larger face". Export as 1080 × 1080.
